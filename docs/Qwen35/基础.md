**📚 VibeCoding 完整学习计划文档**

**一、学习目标**

- 从零开始掌握 VibeCoding + Flutter 开发，实现高效跨平台应用开发。
- 通过每日打卡、每周实战，逐步提升需求描述、代码优化、项目构建能力。
- 熟悉 VibeCoding 核心技巧，结合 AI 工具快速生成高质量Flutter代码。

**二、学习阶段划分（4 周）阶段 1：基础入门（第 1 周）主题：环境搭建 + 基本概念 + 简单实战**

**每日打卡练习：**

- **Day 1：环境准备与工具安装**
  - 安装必备工具：Flutter SDK、VS Code/Cursor、AI 工具（如 Claude Code、文心快码）。
  - 创建第一个Flutter项目并运行（使用 `flutter create` 命令）。
  - **打卡任务**：用 VibeCoding 描述需求，让 AI 生成 “Hello World” 页面。
  - **提示词示例**：

“用 VibeCoding 在Flutter中创建一个简洁的启动页，包含居中的标题 ‘Hello VibeCoding’，使用蓝色主题，并添加一个浮动按钮，点击后显示 ‘Welcome to Flutter’ 的 SnackBar。”

- **Day 2：理解 Widget 与布局**
  - 学习 Widget 概念（Stateless/Stateful）、基础布局（如 Row、Column、Scaffold）。
  - 用 VibeCoding 生成简单布局页面（例如：包含图片和文本的列表项）。
  - **打卡任务**：让 AI 生成一个包含顶部导航栏、图片轮播图、底部按钮的页面。
  - **提示词示例**：

“在Flutter中设计一个首页，顶部有应用标题栏，中间是自动轮播的 3 张图片，底部居中放置一个圆角按钮，文本为 ‘立即体验’，点击跳转到新页面。”

- **Day 3：状态管理与路由**
  - 了解 State 管理基础（如 setState）、页面跳转（Navigator）。
  - 用 VibeCoding 实现带状态切换的简单计数器页面。
  - **打卡任务**：生成一个包含计数器按钮的页面，点击后数字+1，并显示在文本中。
  - **提示词示例**：

“创建一个计数器页面，包含一个居中的数字文本（初始为 0），下方有一个悬浮按钮，点击后数字加 1，并实时更新文本。使用 Riverpod 管理状态。”

- **Day 4：网络请求与数据展示**
  - 学习基础网络请求（Dio 库）与 JSON 解析。
  - 用 VibeCoding 生成调用 API 并展示列表的页面。
  - **打卡任务**：让 AI 生成一个调用公开 API（如假数据接口）并展示用户列表的页面。
  - **提示词示例**：

“在Flutter中实现一个用户列表页，从 ‘[https://jsonplaceholder.typicode.com/users’](https://jsonplaceholder.typicode.com/users’) 获取数据，展示用户姓名和邮箱，每项用 Card 包裹，带分割线。”

- **Day 5：调试与优化**
  - 使用 DevTools 进行性能分析，优化简单布局。
  - 用 VibeCoding 调整现有代码的性能问题。
  - **打卡任务**：让 AI 优化之前生成的计数器页面，减少不必要的重建。
  - **提示词示例**：

“优化之前的计数器页面，避免每次点击按钮时整个页面重建，仅更新数字部分。使用 Key 和 const 构造函数。”

- **Day 6-7：综合实战（本周项目）**
  - **项目目标**：用 VibeCoding 生成一个天气查询 App（输入城市，显示天气信息）。
  - **步骤**：
    1. 设计页面布局（输入框、查询按钮、天气信息卡片）。
    2. 集成网络请求获取天气 API（如 OpenWeatherMap）。
    3. 处理状态更新（加载中、成功、错误）。
  - **提示词示例**：

“开发一个天气查询应用，包含顶部搜索框输入城市名称，下方显示当前天气信息（温度、图标、描述），使用蓝色渐变背景。集成 OpenWeatherMap API，确保输入错误时显示错误提示。”

**阶段 2：进阶实战（第 2-3 周）主题：复杂 UI、插件集成、混合开发、状态管理**

**每周实战项目：**

- **第 2 周：仿写一个电商商品详情页**
  - 目标：包含轮播图、商品信息、价格、购物车按钮、用户评价列表。
  - 集成第三方库（如 carousel_slider、rating_bar）。
  - 使用 Provider 进行状态管理（如购物车数量同步）。
  - **提示词示例**：

“仿写一个电商详情页，顶部是商品图片轮播，中间显示标题、价格、描述，底部有加入购物车按钮和用户评分组件（5 星评分 + 评论数量）。使用 Provider 管理购物车数量，点击按钮时数量+1。”

- **第 3 周：Flutter 混合开发实战**
  - 目标：在现有原生项目（Android/iOS）中集成Flutter页面。
  - 实现原生与Flutter通信（如传递数据、调用方法）。
  - **提示词示例**：

“将现有的 Android 应用集成Flutter页面，从原生 Activity 跳转到一个Flutter制作的订单列表页，并传递用户 ID 参数。在Flutter页面中，点击订单可回调原生方法打开详情页。”

**阶段 3：高级应用与优化（第 4 周）主题：性能优化、组件化、发布上线**

**每日任务：**

- **Day 1-2：性能优化**
  - 使用 Profile 模式分析应用性能瓶颈。
  - 优化列表滑动流畅度（如 ListView.builder、懒加载）。
  - **提示词示例**：

“优化之前生成的商品列表页，确保滚动流畅，使用懒加载模式，并减少不必要的组件重建。”

- **Day 3-4：组件化与复用**
  - 封装自定义组件（如可复用的底部导航栏）。
  - 创建自定义包（package）并发布到 pub。
  - **提示词示例**：

“封装一个底部导航栏组件，包含 3 个选项卡（首页、分类、我的），支持切换时高亮当前项，并触发页面跳转。将其打包为可复用的 package。”

- **Day 5-7：打包与发布**
  - 生成 Android 和 iOS 安装包（APK/IPA）。
  - 配置应用图标、启动页、权限等。
  - 发布到应用商店（如 TestFlight、Google Play）。
  - **提示词示例**：

“打包并发布之前的天气应用，配置应用图标为动态图标（显示当前天气图标），生成 release 版本，并生成适配不同分辨率的启动页图片。”

**四、避坑指南与注意事项**

1. **明确需求**：避免模糊描述，例如 “做一个好看的页面” → 应改为 “设计一个带有霓虹灯效果的登录页，背景为暗紫色，输入框带悬浮动画”。
2. **代码审查**：AI 生成的代码需人工检查逻辑、安全漏洞（如网络请求是否处理异常）。
3. **持续反馈**：每次生成代码后，用自然语言描述优化点，如 “将文本字体改为思源黑体，并添加阴影效果”。
