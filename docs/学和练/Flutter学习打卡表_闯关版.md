## XP 规则

- 完成主线：+10 XP
- 完成改造：+5 XP
- 完成挑战：+10 XP
- 连续学习 3 天：+10 XP
- 连续学习 7 天：+30 XP

## 章节路线

### Chapter 1 能跑起来
- 环境搭建
- 第一个项目
- 修改标题和样式
- 加一个按钮
- 小 Boss：跑通并改造首页

### Chapter 2 会写基础页面
- `Text`
- `Container`
- `Row`
- `Column`
- `Expanded`
- 小 Boss：做出一个完整布局页

### Chapter 3 页面会动
- `setState`
- 按钮点击
- 文本更新
- 表单输入
- 小 Boss：做出一个有交互的页面

### Chapter 4 接入数据
- `Future`
- `async/await`
- 网络请求
- JSON
- loading / error / empty
- 小 Boss：做出一个数据页面

### Chapter 5 综合实战
- 项目串联
- 页面跳转
- 组件复用
- 调试修复
- 小 Boss：完成一个小项目
