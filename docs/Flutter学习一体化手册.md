这本手册采用 **练习驱动 + 多邻国式闯关** 的方式：

- 每天一个主线关卡

- 前一天学的，后一天继续用

你不需要在很多文档之间来回切换。

## 关键 Flutter Skill 清单（练习版）

### 1. Widget 基础
- 重点：`StatelessWidget` / `StatefulWidget` / `BuildContext`
- 练法：同一个页面写两遍，对比区别

### 2. 布局系统
- 重点：`Row` / `Column` / `Expanded` / `Stack` / 约束
- 练法：故意制造 overflow，再修复

### 3. 状态更新
- 重点：`setState`
- 练法：计数器、切换文本、按钮联动

### 4. 路由导航
- 重点：`Navigator` / 参数传递 / 返回结果
- 练法：列表 -> 详情 -> 编辑 -> 返回刷新

### 5. 表单输入
- 重点：`TextField` / `Form` / 校验 / 焦点
- 练法：登录表单 + 错误提示

### 6. 异步处理
- 重点：`Future` / `async/await` / `FutureBuilder` / `Stream`
- 练法：模拟加载 + 真实请求 + 四态页面

### 7. 网络请求
- 重点：`dio` / 拦截器 / 错误处理
- 练法：封装请求层 + 统一错误提示

### 8. 数据模型
- 重点：构造函数、`factory`、`fromJson`
- 练法：手写 JSON 解析，再优化成生成模型

### 9. 状态管理
- 重点：`Riverpod` / `Provider` / `ChangeNotifier`
- 练法：先 setState，再迁移到 Riverpod

### 10. 工程化与优化
- 重点：`const`、列表懒加载、测试、调试、打包
- 练法：同页面前后对比优化效果

## 官方技能坑点提醒

- `setState` 后的异步回调要先确认 `mounted`
- 列表项一定要关注 `Key`
- `FutureBuilder` 不要在 rebuild 时反复创建 future
- `BuildContext` 在异步后可能失效
- `dispose` 要完整清理：`Timer`、`StreamSubscription`、`Controller`
- `GlobalKey` 不要滥用
- 路由参数要做类型和空值校验
- 图片、平台通道、原生能力都要考虑异常捕获
