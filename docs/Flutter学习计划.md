# Flutter VibeCoding 学习计划

## 目标

面向有 Web 开发经验、希望系统学习 Flutter 的开发者，使用 VibeCoding 的方式，从“会看懂”逐步走到“能独立做出可运行、可维护、可复盘的 Flutter 项目”。

这份计划的核心不是堆概念，而是把学习拆成可执行的小步：

- 先建立 Flutter 的认知模型
- 再完成最小可运行页面
- 然后逐步加入状态、列表、网络请求、路由、表单
- 最后完成一个完整小项目并复盘

---

## 学习原则

1. **先做最小可运行版本**，不要一开始追求“大而全”。
2. **优先用 Web 类比理解 Flutter**，但不要把 Flutter 当成 DOM + CSS。
3. **每个知识点都要配一个小练习**，学完就改，改完就跑。
4. **先用 `setState` 做出效果，再考虑状态管理升级**。
5. **遇到报错先定位问题，再讨论重构**。
6. **每周都要有一个小项目或阶段成果**，形成可见进展。

---

## 四周学习路线

### 第 1 周：Flutter 入门与基础认知

**目标**：能跑起来、看懂页面结构、理解 Widget、布局、基础交互。

**重点内容**
- Flutter 环境搭建
- `flutter doctor`、`flutter run`、`flutter pub get`
- Dart 基础语法：变量、函数、类、空安全、异步基础
- Widget 思维：`Scaffold`、`Container`、`Text`、`Image`、`Button`
- 基础布局：`Row`、`Column`、`Stack`、`Expanded`
- 最小交互：按钮点击、文本更新、简单表单输入

**本周成果**
- Hello World 页面
- 计数器页面改造版
- 个人名片页
- 商品卡片页

**练习方式**
- 每天 1 个小任务
- 每个任务做 2 个改造：改样式、改文案、改交互
- 记录遇到的报错和解决方法

---

### 第 2 周：页面交互与状态驱动 UI

**目标**：理解“状态变化驱动 UI 更新”，能完成多页面和更复杂交互。

**重点内容**
- `setState` 的正确使用
- 表单输入与校验
- 条件渲染、空状态、加载状态
- 页面跳转与参数传递
- 列表渲染与列表项拆分
- 组件复用与简单目录拆分

**本周成果**
- 登录页 / 注册页
- 待办事项列表
- 带详情页的列表项目
- 带 loading / empty / error 的数据页

**练习方式**
- 先用最简单的状态写法实现功能
- 再尝试把页面拆成 2~3 个组件
- 对比 Web 中组件和状态管理的写法差异

---

### 第 3 周：网络请求、本地数据与项目结构

**目标**：接入真实数据，能组织一个中小型 Flutter 项目。

**重点内容**
- `Future`、`async/await`
- 网络请求与 JSON 解析
- 请求错误处理与重试
- 本地存储基础
- 页面结构设计
- 简单的分层思路：页面、组件、数据、服务

**本周成果**
- 用户列表页
- 天气查询页
- 简单缓存或本地保存功能
- 统一处理 loading / error / empty

**练习方式**
- 每次请求都同时处理成功、失败、空数据三种情况
- 用真实接口练习 JSON 解析
- 让 AI 帮你先生成，再自己补齐错误处理

---

### 第 4 周：综合项目与发布准备

**目标**：做出一个完整小项目，具备基本工程意识。

**重点内容**
- 项目整合与页面串联
- 状态管理入门或升级
- 性能基础优化
- 调试与排错
- 打包基础、图标、启动页、权限
- 发布前检查清单

**本周成果**
- 一个完整的小型 Flutter 应用
- 一个可展示的项目 README
- 一份学习复盘总结

**推荐项目方向**
- Todo List 升级版
- 天气查询 App
- 简单商品列表 + 详情 + 收藏
- 学习打卡 App

---

## 每日学习模板

每一天尽量按这个节奏推进：

1. **10 分钟复习**：回顾昨天内容
2. **20 分钟理解**：看懂今天的新概念
3. **40 分钟动手**：写代码并跑起来
4. **10 分钟复盘**：记录报错、心得、可改造点

## Flutter 学习中的 Web 类比

- React/Vue 组件树 ≈ Flutter Widget 树
- Flex 布局 ≈ Row / Column / Expanded
- state 更新 UI ≈ `setState` 驱动重建
- React Router ≈ Navigator / GoRouter
- Promise / async-await ≈ Future / async-await
- axios ≈ dio

注意：这些只是帮助理解的类比，不要机械照搬 Web 思维。

---

## 常见学习策略

1. **先能跑，再理解为什么。**
2. **先复制最小示例，再逐步改造。**
3. **先解决一个问题，再扩展一层。**
4. **每次学习都保留一个可运行版本。**
5. **每周都整理一次“我已经会什么”清单。**

---

## 学习检查清单

你可以用下面的问题检查自己是否真的掌握：

- 我能解释 Widget 树是什么吗？
- 我能用 `Row` 和 `Column` 做基本布局吗？
- 我知道什么时候用 `setState` 吗？
- 我能写一个带 loading 的页面吗？
- 我能把接口返回的数据渲染成列表吗？
- 我能独立排查一次 Flutter 报错吗？
- 我能做出一个完整的小项目吗？

---

## 建议的学习节奏

- 每天 1~2 小时
- 每周至少 5 天学习
- 每周末做一次小复盘
- 每 2 周做一次小项目整理

---

## 结束语

Flutter 学习最重要的不是“把所有知识点一次学完”，而是持续做出一个又一个可以运行、可以改、可以复盘的小成果。

如果你愿意，坚持 4 周，你会明显感觉自己从“看别人写 Flutter”变成“自己能独立写 Flutter”。
