## 一、提示词工具箱

### 1. 基础实现提示词

```text
我是 Flutter 新手，请用 Flutter 3.24+ 帮我实现 XXX。
要求：
1. 代码完整可直接运行
2. 使用空安全语法
3. 带详细注释
4. 先给最小可运行版本
5. 再告诉我可以怎么改造
```

### 2. 练习驱动提示词

```text
我正在做 Flutter 练习，请不要讲太多理论，直接带我完成一个最小可运行任务。
要求：
1. 先给今天的练习目标
2. 再给最小代码
3. 再给一个改造动作
4. 再给一个复用昨天知识的动作
5. 再给一个常见错误排查点
```

### 3. 高效问法提示词

```text
我在学 Flutter，请帮我实现一个商品列表页：
- 数据：10 个假数据（商品名、价格、图片 URL）
- UI：卡片式布局，图片在上，文字在下，价格用红色粗体
- 交互：点击卡片弹出底部弹窗（BottomSheet）显示详情
- 要求：图片加载时显示占位图，用 GridView 实现
- 请解释：GridView.builder 和普通 GridView 的性能区别
```

### 4. 追问提示词

```text
我看不懂这段 Flutter 代码，请你逐行解释，并告诉我：
1. 这行代码在做什么
2. 和 Web 开发里的什么最像
3. 如果我改成另一种写法，会有什么区别
4. 这段代码在真实项目里通常什么时候用
```

### 5. 改造提示词

```text
我已经有一份 Flutter 代码了，请不要重写整页，而是在原代码上帮我改造。
我想改的方向是：___
要求：
1. 先告诉我改哪里
2. 再告诉我为什么这样改
3. 再告诉我怎么验证改对了
4. 再给我 1 个额外改造建议
```

### 6. 故意出错提示词

```text
请基于我当前的 Flutter 代码，帮我设计一个容易犯错的改动，让我练习排查错误。
要求：
1. 先告诉我改哪里
2. 再告诉我会出现什么问题
3. 再告诉我怎么自己排查
4. 最后再告诉我正确修复方式
```

### 7. 复盘提示词

```text
请根据我今天的 Flutter 练习，帮我做一个很短的复盘。
只输出 4 项：
1. 今天写了什么
2. 今天改了什么
3. 今天卡在哪
4. 明天继续什么
不要写长总结。
```

### 8. 脑图提示词

```text
请把我今天的 Flutter 学习内容整理成树状脑图大纲，包含：主题、概念、代码、问题、解决方案、收获、明日目标。
```

### 9. 状态与异步提示词

```text
请带我做一个 Flutter 状态/异步练习。
要求：
1. 先用 setState / Future 做出最小效果
2. 再加 loading / error / empty
3. 再告诉我常见坑点
4. 再给我一个复用昨天知识的动作
```

## 二、Vibe Coding 四步法

1. **清晰描述需求**
   - 给出具体功能、风格、数据、交互
   - 越具体，AI 越容易给出可用代码

2. **让 AI 先出方案**
   - 先确认页面结构、实现思路、状态流转
   - 再让 AI 写代码

3. **验收 + 迭代优化**
   - 不满意就继续改
   - 用自然语言告诉 AI：改样式、改布局、改交互、改文案

4. **关键代码审查**
   - AI 生成的代码要人工看
   - 特别检查异常处理、性能、空值、权限、边界情况

## 四、学习方式建议
### 1.Flutter 练习的正确顺序

#### 1.1 先能跑
- 安装 Flutter
- 跑通 `flutter doctor`
- 跑起第一个项目

#### 1.2 再能改
- 改标题
- 改样式
- 改布局
- 改按钮交互

#### 1.3 再能串
- 把前一天学的内容放进今天的新任务里
- 用旧知识完成新页面

#### 1.4 再能错
- 故意改错一次
- 学会排查
- 学会修复

#### 1.5 再能做项目
- 把 Widget、状态、布局、数据、跳转、调试串起来

---

---
#### 1.6 适合你的学习方式
- 如果你有 Web 开发经验，最适合你的方式不是“先把概念背完”，而是：

- 先写一个页面
- 再改两次
- 再把旧知识串进来
- 再做一个小项目
- 再回头查资料补细节

这样学得更快，也更像真正开发。
