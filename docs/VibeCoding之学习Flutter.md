# VibeCoding之学习Flutter

# 一、万能提示词

### 1.我是 Flutter 新手，帮我用 Flutter 3.24+ 实现 XXX，代码完整可直接运行，带详细注释，逐行解释，使用空安全语法。



### 2.✅高效问法（Context + 约束 + 追问）

> **"我在学 Flutter，请帮我实现一个商品列表页：**
>
> - **数据**：10 个假数据（商品名、价格、图片 URL）
>
> - **UI**：瀑布流布局，图片在上，文字在下，价格用红色粗体
>
> - **交互**：点击卡片弹出底部弹窗（BottomSheet）显示详情
>
> - **要求**：图片加载时显示骨架屏（Shimmer），用 `GridView` 实现
>
> - **请解释**：`GridView.builder` 和普通 `GridView` 的性能区别"
>
> **遇到看不懂的代码，继续追问：**
>
> > *"这行* `const EdgeInsets.symmetric(horizontal: 16.0)` *是什么意思？如果改成* `only` *有什么区别？"*



**不要孤立学语法！** 每学一个概念，立刻让 AI 生成 Flutter 代码演示。



**Vibe Coding四步法**

- **清晰描述需求**：给出具体功能、技术栈、风格细节（如"按钮居中、表单带阴影"）
- **让AI先出方案**：确认项目结构、实现思路再生成代码，避免逻辑错误
- **验收+迭代优化**：用自然语言提修改意见，如"把字体换成微软雅黑"
- **关键代码审查**：AI生成的代码需人工检查安全漏洞和性能问题
