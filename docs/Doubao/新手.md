# 豆包-Flutter学习计划-快速（VibeCoding版）

Vibe Coding 从零开始学 Flutter 完整学习计划（含打卡+实战+提示词+专属Skill）

核心原则：以 **Vibe Coding（AI 结对编程）** 为核心，拒绝死记硬背，每天1-2小时，每周1个核心目标，通过“AI 生成→自己调试→实战落地”的流程，快速掌握 Flutter，同步积累专属技能，所有练习均配套可直接复制的 AI 提示词，降低学习门槛，确保每一步都有明确反馈。

适用人群：零基础小白、编程入门者，无需提前掌握 Dart 或其他编程语言，全程 AI 辅助，跟着打卡即可入门、进阶、实战。

前置准备：安装 Flutter SDK（3.24+）、VS Code/Cursor（安装 Flutter、Dart 插件）、AI 工具（Cursor 内置 AI / Claude 3.5 / ChatGPT）、DartPad（在线练语法，无需安装）。

# 第一部分：Flutter 专属 Skill 体系（全程同步积累）

核心：围绕 Flutter 开发全流程，拆解 6 大核心 Skill，每个 Skill 对应每周学习重点，学完即掌握，可直接用于项目开发，打卡时同步确认 Skill 掌握情况。

## Skill 1：Flutter 环境搭建与基础操作（第1周掌握）

- 核心能力：Flutter SDK 安装、环境配置（国内镜像）、flutter 命令使用（create/run/doctor）、IDE 插件配置
- 掌握标准：能独立搭建环境，解决 flutter doctor 常见报错，成功运行第一个 Flutter 项目
- 配套练习：环境搭建打卡任务（第1天）

## Skill 2：Dart 基础语法与 Flutter 适配（第1周掌握）

- 核心能力：变量/类型/空安全、函数（箭头函数/可选参数）、类与继承、异步（Future/async/await）、集合（List/Map）
- 掌握标准：能看懂 Flutter 代码中的 Dart 语法，能修改简单代码，理解空安全的作用
- 配套练习：每日 Dart 语法小练习（第2-3天）

## Skill 3：Flutter 核心 Widget 与布局（第1周掌握）

- 核心能力：StatelessWidget/StatefulWidget 区别、常用组件（Text/Button/Container/Image）、布局组件（Row/Column/Stack/ListView/GridView）
- 掌握标准：能通过 AI 生成基础页面，修改组件样式、调整布局，理解“万物皆 Widget”
- 配套练习：每日组件/布局实战（第4-7天）

## Skill 4：Flutter 状态管理与页面导航（第2周掌握）

- 核心能力：setState 基础状态管理、Riverpod 2.0（主流）、页面跳转（Navigator/GoRouter）、页面传参
- 掌握标准：能实现多页面跳转，用 Riverpod 管理跨页面数据，理解状态管理的核心逻辑
- 配套练习：状态管理重构、多页面实战（第8-14天）

## Skill 5：Flutter 交互、存储与网络请求（第3周掌握）

- 核心能力：表单验证、本地存储（SharedPreferences/Hive）、网络请求（dio）、JSON 解析
- 掌握标准：能实现登录表单、本地数据持久化、调用公开 API 并渲染数据
- 配套练习：表单实战、网络请求实战（第15-20天）

## Skill 6：Flutter 项目实战与打包发布（第4周掌握）

- 核心能力：项目结构搭建、功能整合、Bug 调试、Android/iOS 打包基础
- 掌握标准：能独立完成一个完整小项目，解决常见 Bug，生成 Android APK
- 配套练习：完整项目开发、打包实战（第21-28天）
