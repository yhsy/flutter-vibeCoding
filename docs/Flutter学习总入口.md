# Flutter 学习总入口

这是你的 Flutter 学习“总控制台”。

你可以把它当成：

- 学习导航页
- 每日打卡入口
- 进度追踪入口
- 脑图整理入口
- AI 提示词入口
- 闯关记录入口

它的目标只有一个：**让你每天打开这一页，就知道今天学什么、怎么记、怎么复盘、怎么生成脑图。**

## 二、学习流程总览

### 1. 开始前
- 打开 Flutter 学习计划
- 确认今天的章节和目标
- 看一遍昨天的复盘

### 2. 学习中
- 先看最小概念
- 再写最小可运行代码
- 再做 1~2 个改造
- 再记录卡点和解决方案

### 3. 学完后
- 填写每日打卡
- 写学习笔记
- 记录编码成果
- 补一个脑图节点
- 更新进度

## 三、每日学习模板

你每天只需要按这个顺序走：

### Step 1. 看今天学什么
- 今天的主线任务是什么？
- 今天的目标是理解概念，还是完成页面？

### Step 2. 写最小代码
- 先做能跑的版本
- 先别追求优雅
- 先让功能成立

### Step 3. 做二次改造
- 改样式
- 改文案
- 改交互
- 改布局

### Step 4. 记录学习内容
- 今日编码
- 今日笔记
- 今日学习记录
- 今日问题与解决方案
- 今日复盘

### Step 5. 生成脑图
把当天内容整理成下面的结构：
- 今日主题
- 核心概念
- 今日代码
- 今日问题
- 今日解法
- 今日收获
- 明日目标

## 五、进度追踪方式

- 环境搭建
- Dart 基础
- Widget 与布局
- 状态与交互
- 网络与数据
- 综合项目
- 打包与复盘

### 2. 看每日状态
- 是否完成主线
- 是否完成加分任务
- 是否完成挑战任务
- 是否记录了笔记
- 是否做了复盘

### 3. 看成长轨迹
- 今天和昨天比，进步了什么
- 这个星期和上个星期比，解锁了什么
- 这个月能不能独立做一个完整页面

## 六、脑图生成工作流

### 方案 A：最轻量
每天只记 6 个节点：
- 今日主题
- 今日主线
- 今日编码
- 今日笔记
- 今日卡点
- 今日收获

### 方案 B：周复盘脑图
每周整理一次：
- 本周主题
- 本周完成关卡
- 本周核心概念
- 本周代码成果
- 本周问题与解决
- 下周升级点

### 方案 C：章节脑图
每完成一个章节就整理一次：
- 章节名称
- 学习目标
- 核心概念
- 关键代码
- 错误与修复
- 个人理解

## 八、如果你想更像多邻国

你可以把学习当成“闯关”：

- 每天一个主线关卡

- 每周打一只 Boss

**每天都能推进一点点，留下记录，形成复盘，并且看见自己在变强。**

## 九、直接可用的 AI 提示词

### 1. 学习辅导
```text
我正在学 Flutter，请按“先解释、再类比 Web、再给最小代码、再给练习”的方式教我：___。
```

### 2. 代码陪练
```text
请带我一步步写一个 Flutter 页面：___。
要求：先拆结构，再写代码，再做改造，再给我一个打卡模板。
```

### 3. 调试助手
```text
你现在是我的 Flutter 调试助手。
我遇到的问题是：___。
请先判断最可能的 3 个原因，再按优先级给我排查步骤。
```

### 4. 复盘助手
```text
请根据我今天的 Flutter 学习记录帮我复盘：___。
请输出：今天掌握了什么、卡在哪、明天要补什么、给我一个 30 分钟补练任务。
```

### 5. 脑图助手
```text
请把我今天的 Flutter 学习内容整理成树状脑图大纲，包含：主题、概念、代码、问题、解决方案、收获、明日目标。
```
