# Flutter 学习打卡表 / 闯关版

## 你的学习游戏化规则

把 Flutter 学习当成一款“闯关游戏”来玩：

- 每天只打 1 个主线关卡
- 完成后获得经验值（XP）
- 做加分任务可以额外加分
- 完成连续学习会触发连击奖励
- 每周会遇到一次周 Boss（复盘关）
- 每个阶段结束后解锁一个新技能
- 每天记录不仅是结果，还包括心情、专注度、卡点和明日目标
